# 社内ポータル

iPLAss × Claude Code で作成した社内ポータルのサンプルアプリです。

## 機能

- **お知らせ一覧 / 詳細表示** — カテゴリによる絞り込みに対応
- **スケジュールカレンダー** — 月 / 週 / リスト表示の切り替え
- **ドキュメント管理** — ファイルの一覧表示、ダウンロード
- **レスポンシブ対応** — スマートフォンからの閲覧にも対応

## 含まれるデータ

`iplass-portal-package.zip` には以下が含まれます。

- メタデータ（Entity / Action / Command / Template 定義）
- サンプルデータ（お知らせ・スケジュール・ドキュメント）
